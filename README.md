# FlowLens-
FlowLens（交我 Pay）是一款面向个人的本地化多平台账单整理与收支分析工具，目标不是简单汇总流水，而是帮助用户算清一段时间内真正支出了多少钱。项目支持导入微信、支付宝、银行等来源的 CSV、Excel、PDF 账单，在本机完成读取、OCR、标准化和人工核验，并以原始底稿和追加式修订保证过程可追溯。当前重构版本已完成第一阶段：统一账本、批次追加、缺口提示、来源汇总、持久化恢复和有效流水导出；尚未把来源流水直接等同于真实支出。后续将围绕跨平台重复交易、账户转移、退款回款、消费分类及个性化口径，结合确定性规则、AI 判断和用户复核，形成可信、可解释、可纠错的结果。项目默认仅监听本机，不上传原始数据，也不以模型接入或测试通过替代体验验收，把一次性的表格整理转化为可持续改进的个人财务复盘流程。
